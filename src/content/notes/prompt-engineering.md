LLM에게 원하는 결과를 얻기 위해 입력(프롬프트)을 설계하는 기술.
모델의 능력을 최대한 끌어내는 것이 목표다.

## 핵심 기법

### 역할 부여 (Role Prompting)
```
당신은 10년 경력의 시니어 소프트웨어 엔지니어입니다.
```
모델에게 특정 페르소나를 부여해 응답 품질을 높인다.

### 예시 제공 (Few-shot)
원하는 형식의 예시를 2~3개 보여준 뒤 새 입력을 처리하게 한다.

### 생각의 사슬 (Chain-of-Thought)
```
단계별로 생각해보세요.
```
복잡한 추론 과제에서 중간 과정을 명시하게 해 정확도를 높인다.

### 구조화된 출력
JSON, 표, 목록 등 특정 형식으로 출력하도록 명시한다.

## LLM 에이전트에서의 활용

[[llm-agents]]는 프롬프트 엔지니어링을 자동화된 워크플로우로 확장한 것이다.
에이전트의 시스템 프롬프트가 곧 그 에이전트의 역량을 결정한다.
